Mouse Escape Game

A fast-paced 2D arcade rescue game built with HTML and JavaScript.

How to Play
- Use the Arrow Keys to move the mouse.
- Grab the Golden Key to unlock the exit door and gain +5 seconds of bonus time.
- Avoid the 4 patrolling cats and dodge the projectiles fired by the tracking turrets.
- Reach the safe house before the timer ends!

Features
- 3 Difficulty modes (Easy, Medium, Hard)
- Sound effects and volume control using Web Audio API
- Customizable mouse colors and arena themes (Light / Night)
- Persistent High Score saved locally
